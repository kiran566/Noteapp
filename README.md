# 📝 Fullstack TODO / Notes Application

A full-featured ** Notes App** built using the MERN stack. This application allows users to securely manage their daily tasks with authentication and user-specific data handling.

---

## 🚀 Features

* 🔐 User Authentication (Signup & Login)
* 📝 Create, Read, Update, Delete (CRUD) tasks/notes
* ✅ Mark tasks as completed
* ❌ Delete tasks
* 👤 User-specific data (each user sees only their tasks)
* ⚡ Responsive UI for all devices
* 🔄 Real-time updates after actions

---

## 🛠️ Tech Stack

### Frontend:

* React.js

* JavaScript (ES6+)

### Backend:

* Node.js

### Database:

* MongoDB

### Tools:

* Git & GitHub

## 📂 Project Structure

/client  → React frontend
/server  → Node.js backend

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/kiran566/Noteapp
cd Npteapp
```

### 2. Setup Backend

```bash
cd server
npm install
npm start
```

### 3. Setup Frontend

```bash
cd client
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file in the server folder and add:
